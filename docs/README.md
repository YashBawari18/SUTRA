## Key Design Principles Highlighted in Documentation

1. **Investigative Decision Support**: SŪTRA is explicitly designed for evidentiary discovery and pattern tracing, not automated accusation.
2. **Explainable AI & Mathematical Transparency**: Every risk score and graph metric provides traceable evidence breakdown.
3. **Air-Gapped & Secure Operation**: Operates with zero external CDN dependencies for high-security environments.
4. **Institutional Role-Based Access Control**: Strict segregation between investigator, analyst, and administrator roles.
